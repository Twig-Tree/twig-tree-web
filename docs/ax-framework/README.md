# AX Framework

> 상태: 초안

불명확한 사용자 피드백을 팀이 판단하고 검증할 수 있는 제품 변경으로 발전시키기 위한 가벼운 작업 프레임워크다.

이 디렉토리의 문서는 완성된 규약이 아니다. 실제 사례를 통과시키면서 필요한 단계와 산출물을 발견하고, 불필요한 구조는 제거한다.

## 현재의 사용법

1. 사용자 피드백을 `문제 정제` 단계에서 관찰 가능한 문제로 바꾼다.
2. 성격이 다른 대응 후보를 만든다.
3. 사람이 후보를 선택하거나 조합한다.
4. 판단에 필요한 최소 프로토타입을 만든다.
5. 결정한 내용을 구현하고 확인 가능한 결과물로 전달한다.
6. 피드백을 반영하며 검증과 구현을 반복한다.

단계는 체크리스트가 아니라 **다음 결정을 내리기 위한 장치**다. 이미 충분히 확인된 내용까지 형식적으로 다시 작성할 필요는 없다.

## 문서 변경 원칙

- 현재는 문장 단위의 안정성보다 **문서 역할의 분리와 재배치 용이성**을 우선한다.
- 확정되지 않은 내용은 규칙처럼 쓰지 않고 `가설`, `예시`, `열린 질문`으로 표시한다.
- 용어의 정의는 [glossary.md](./glossary.md)를 단일 출처로 삼는다.
- 구조적 결정과 그 이유는 [design-notes.md](./design-notes.md)에 짧게 남긴다.
- 실제 사례에서 반복해 유효했던 요소만 프레임워크 본문으로 승격한다.
