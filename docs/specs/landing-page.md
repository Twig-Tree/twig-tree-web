# 소개 페이지

로그인 전 사용자가 사이트에 처음 들어왔을 때 보는 페이지다. 서비스가 무엇인지 설명하고 로그인으로 안내한다.

디자인 시안 원본은 [landing-page-design.html](./landing-page-design.html)이다. 레이아웃·색·카피는 시안을 따르고, 아래에 적은 부분만 시안과 다르게 구현했다.

## 라우트와 레이아웃

- `/`가 소개 페이지다(`app/(landing)/page.tsx`).
- 로그인한 사용자도 대시보드로 보내지 않는다. "로그인"과 "무료로 시작하기"는 `/login`으로 가고, 로그인 화면이 세션을 확인해 대시보드로 보낸다.
- 소개 페이지에는 앱 상단바가 없고 문서 전체가 스크롤된다. 앱 화면(`(main)`, `(auth)`, `(dev)`)은 `widgets/app-shell`이 상단바와 화면 높이 셸을 붙인다.
- 로그인 화면 상단바의 로고는 소개 페이지로, 메인 화면 상단바의 로고는 대시보드로 간다.

코드는 `src/widgets/landing/`에 있다.

## 색과 형태

소개 페이지는 사용자가 고른 테마를 따르지 않는다. 로그인 전이라 테마를 고를 기회가 없었고, 밝은 섹션과 어두운 섹션을 함께 써서 팔레트 한 벌로 완결된다.

값은 `app/themes/landing.css`의 `--color-landing-*` 에 있고, 컴포넌트는 `bg-landing-brand`처럼 역할 이름만 쓴다. 규칙은 [테마 규칙의 소개 페이지 절](../conventions/theming.md#소개-페이지)에 있다.

| 역할      | 값        | 용도                            |
| --------- | --------- | ------------------------------- |
| ink       | `#17211B` | 본문 글자, 어두운 섹션 바탕     |
| brand     | `#2F6B45` | 워드마크 "tree", CTA 바탕, 라벨 |
| leaf      | `#58A86B` | 현재 강의 노드, 진행바, 강조    |
| leaf-soft | `#EAF4EC` | 배지, 아이콘 바탕               |
| edge      | `#9CC5A6` | 트리 연결선                     |
| muted     | `#4A5A4F` | 보조 글자                       |

글자와 바탕 조합은 `themes.test.ts`의 `landingTextPairs`가 4.5:1 대비를 검사한다. 시안에서 아직 지나지 않은 강의 노드의 글자(`#7F9486`)는 3.93:1이라 `#8FA596`으로 올렸다.

- 폰트: Inter(라틴) + Noto Sans KR(한글). `next/font/google`로 소개 페이지에만 적용한다.
- 제목: weight 800, letter-spacing -0.03 ~ -0.035em. 데스크톱 기준 h1 64px, h2 40px(강의 섹션 52px, CTA 48px)이고 좁은 화면에서는 `clamp()`로 줄인다.
- 한글은 단어 중간에서 줄을 바꾸지 않는다(`word-break: keep-all`).
- 컨테이너: 최대 폭 1200px, 좌우 여백 24px.

## 로고

로고는 팀 로고 PNG(`src/shared/ui/logo`)를 쓴다. 상단바와 Footer는 원본 색, CTA는 브랜드 바탕에서 보이도록 흰색 실루엣이다. 자세한 내용은 [테마 규칙의 로고 절](../conventions/theming.md#로고)에 있다.

## 섹션 구성

위에서 아래 순서다.

1. **TopBar**: 왼쪽 로고, 오른쪽 "로그인". 고정하지 않는다.
2. **Hero**: 배지, h1 "흩어진 지식, 한 그루의 트리로", 서브카피, "무료로 시작하기"(`/login`)와 "30초 데모 보기"(`#lecture`). 오른쪽은 브라우저 창 안의 예시 트리.
3. **Problem**: "PDF 30장, 어디서부터 읽어야 할까요?"와 카드 3개.
4. **How it works** (`#features`): 세 단계 카드. 마지막 단계만 어두운 카드.
5. **AI 트리 생성**: 왼쪽 설명과 체크 3개, 오른쪽 BEFORE(문서) → AFTER(트리) 그림. 좁은 화면에서는 세로로 쌓고 화살표가 아래를 향한다.
6. **트리 강의** (`#lecture`): [트리 강의 데모](#트리-강의-데모).
7. **편집·메모·검색**: flex-wrap 배치. 편집 `flex: 2 1 520px`, 메모 `flex: 1 1 300px`, 검색 `flex: 1 1 100%`. grid의 `auto-fit`과 `span 2`를 쓰면 중간 폭에서 메모 카드만 좁게 남는다.
8. **사용자 테스트**: 통계 카드 3개. 값은 실제 설문 결과가 나올 때까지 `[N]%` 자리 표시를 유지하고 임의의 숫자를 넣지 않는다.
9. **CTA** (`#start`): 브랜드 바탕, 흰색 로고, "첫 번째 트리를 심어보세요", "무료로 시작하기"(`/login`).
10. **Footer**: 로고, "팀 백색소음 · 홍익대학교 컴퓨터공학과 졸업 프로젝트", [GitHub](https://github.com/Twig-Tree).

검색 카드의 입력창은 동작하지 않는 예시라 실제 `input`이 아니라 입력창 모양만 그린다. 실제 `input`이면 포커스되어 쓸 수 있는 것처럼 보인다.

## 트리 강의 데모

화면(카메라)이 노드를 따라 이동하며 해설이 바뀐다. 슬라이드 방식이 아니고, 목차 패널과 노드 클릭 이동은 없다.

데이터는 `model/lectureDemoData.ts`에 있다. 캔버스는 560×340, 노드는 140×40 알약 모양이다. 연결선은 부모의 오른쪽 끝 중앙에서 자식의 왼쪽 끝 중앙까지 베지어 곡선으로 잇는다.

| 순서 | 노드        | 부모        |
| ---- | ----------- | ----------- |
| 1    | 운영체제    | -           |
| 2    | 프로세스    | 운영체제    |
| 3    | 스케줄링    | 프로세스    |
| 4    | 동기화      | 프로세스    |
| 5    | 메모리 관리 | 운영체제    |
| 6    | 가상 메모리 | 메모리 관리 |

파일 시스템(부모: 운영체제)은 트리에는 있지만 이 예시 강의에서는 다루지 않는다.

### 카메라

트리 캔버스의 왼쪽 위를 뷰포트 중앙에 두고, 현재 노드의 중심이 그 자리에 오도록 옮긴다. 배율은 1.3, 이동은 0.9초(`cubic-bezier(0.65, 0, 0.35, 1)`)다. 뷰포트 높이는 420px이다.

### 노드 상태

| 상태      | 모양                          |
| --------- | ----------------------------- |
| 현재      | leaf 바탕, 연한 테두리, 빛 링 |
| 지나온    | brand 바탕                    |
| 남은 노드 | 어두운 회색                   |

### 재생

- 재생 중에는 노드마다 3.6초를 머문 뒤 다음으로 넘어가고, 마지막 다음에는 처음으로 돌아간다.
- 재생 중에 직접 넘긴 노드도 3.6초를 처음부터 센다.
- 이전·다음 버튼은 처음과 끝에서 비활성화된다. 버튼은 44px 이상이다.
- 섹션이 화면에 들어오면 자동 재생하고, 벗어나면 멈춘다. 보이지 않는 곳에서 강의가 넘어가면 돌아왔을 때 흐름을 놓치기 때문이다.
- 사용자가 직접 멈춘 데모는 화면에 다시 들어와도 자동 재생하지 않는다.

### 접근성

- 트리 그림은 장식으로 처리하고, 같은 내용은 해설 문단이 전한다. 해설 앞에 현재 노드 이름을 화면에 보이지 않게 붙인다.
- 해설 문단의 `aria-live`는 멈춰 있을 때만 `polite`다. 재생 중에는 3.6초마다 끼어들지 않도록 `off`로 둔다.
- 진행바는 `progressbar` 역할과 현재 단계 값을 가진다.

## 애니메이션

`motion` 패키지(`motion/react`)를 쓴다. `framer-motion`의 새 이름이다.

- **Hero 트리**: 연결선이 `pathLength` 0→1로 1.3초 동안 그려지고, 노드가 시안의 지연값대로 순서대로 나타난다.
- **섹션 제목과 카드**: 화면에 처음 들어올 때 아래에서 24px 올라오며 나타난다(`Reveal`). 같은 줄의 카드는 0.08초씩 차례로 나온다.

움직임을 줄인 사용자(`prefers-reduced-motion`)에게는 전환 시간을 0으로 두어 바로 보여준다. 강의 데모는 자동 재생하지 않고 카메라도 바로 옮긴다. 처음 상태(`initial`)를 설정에 따라 바꾸지 않는 것은, 서버가 그린 투명 상태와 클라이언트 값이 어긋나 요소가 보이지 않은 채 남을 수 있어서다.

등장 애니메이션 때문에 섹션은 처음에 투명하게 그려진다. JavaScript가 꺼진 브라우저에서는 Hero 아래 섹션이 보이지 않는다.
