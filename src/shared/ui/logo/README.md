# 로고

| 파일                           | 모양                       | 쓰는 곳                                     |
| ------------------------------ | -------------------------- | ------------------------------------------- |
| `Twig-Tree-logo.png`           | 심볼 + 워드마크 (가로형)   | `<Logo />` — 앱 상단바, 로그인, 소개 페이지 |
| `Twig-Tree-symbol.png`         | 심볼만, 투명 배경          | 아직 없음                                   |
| `Twig-Tree-app-icon-green.png` | 초록 둥근 사각형 + 흰 심볼 | 아직 없음                                   |

브라우저 탭 아이콘은 Next.js 파일 규칙에 따라 `app/icon.png`(어두운 둥근 사각형 + 흰 줄기·초록 잎)에 따로 둔다.

로고 PNG는 줄기와 글자가 어두운 색이라 어두운 바탕에서는 보이지 않는다. 테마가 정하는 필터는 [테마 규칙](../../../../docs/conventions/theming.md#로고)에 있다.
